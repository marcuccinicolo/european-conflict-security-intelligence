# data/reference — small hand-coded reference tables (committed)

| File | Content | Source |
|---|---|---|
| `nato_accession.csv` | NATO accession date of each European member (Germany: Federal Republic, 1955) | NATO, *Member countries*, https://www.nato.int/cps/en/natohq/topics_52044.htm |

Coding rule used in the analysis: a country counts as a NATO member in year *t* if it acceded on
or before 31 December of *t*. European non-members (e.g. Austria, Ireland, Switzerland, Cyprus,
Malta, Serbia) are absent from the table and coded as non-members in every year.
